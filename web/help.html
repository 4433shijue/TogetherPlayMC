TOGETHERPLAYMC · WINDOWS

第一次和小球一起玩 MC

启动器负责打开 Minecraft，「一起玩 MC」负责把伙伴装进你选的游戏。先把「一起玩 MC」的 Windows 压缩包完整解压到固定文件夹，再打开里面的程序。游戏整合包可以保留原样，不用和程序解压到一起。

  • 我刚下载了一个整合包，想让小球加入
  • 我已经在玩了，想给现有版本装小球
  • 我已经装好伙伴，下次怎么开玩？

先打开「一起玩 MC」

用桌面版就双击 TogetherPlayMC.exe，点「开始连接」。用网页版就双击 start-together.cmd，保留打开的命令窗口。两种方式选一种即可，共用同一份伙伴和设置。

刚下载了整合包 ABC，怎么让小球加入？

假设你刚下载了 ABC.zip。可以先把包拖进控制台，再去启动器安装。留意三条提示。「资料已保存」说明原包读好了，「已关联」说明选好了游戏目录，看到「已安装」才说明小球的模组装好了。

  1. 让控制台读包。在「连接与安装」的「本地整合包资料库」，把 ABC.zip 拖到「选择或拖入整合包」。等到「资料已保存」，就能查看识别出的游戏版本、加载器和包内资料。这一步不会改动游戏。
  2. 在启动器里安装 ABC。用 PCL 或你平时的 MC 启动器导入同一个包，等它安装完成。已经装好的可以跳过安装。在启动器里选中 ABC，打开它实际使用的游戏文件夹，记下路径。不要选下载目录，也不要把压缩包里解出来的 overrides 当成游戏目录。
  3. 把资料绑定到你会启动的那个 ABC。回到资料库，展开「匹配目录」。桌面版可点「选择匹配目录」选刚才的文件夹，网页版粘贴路径后点「记住目录」。点「重新核对」，从「游戏实例」里选中路径一致的 ABC，再点「确认绑定」。有两个同名结果时，以启动器打开的目录为准，并核对版本、加载器和文件差异。
  4. 给这个 ABC 安装伙伴。如果 MC 还开着，先保存存档并关闭游戏窗口。在「已关联」的 ABC 下面点「安装伙伴」，等到出现「已安装」和模组文件名，再开游戏。
  5. 进单人世界见小球。保持本地服务运行，用启动器启动刚装好伙伴的 ABC，进入一个单人存档。想确认是否连上或开口聊天，接着看进世界后怎么看、怎么聊。

能读包，不一定能装小球。目前游戏内伙伴支持 Minecraft Java 版的 1.20.1 Fabric、1.20.1 Forge、1.21.1 Fabric。其他版本仍可查阅识别到的资料；如果实例显示「仅可查资料」，就不会有「安装伙伴」按钮。原包只有清单时，可以在关联后点「从实例补全资料」。

已经在玩的版本，没有压缩包也能装

已经按上面给 ABC 安装了伙伴，可以直接去游戏里见小球。给其他现有版本安装时，在「连接与安装」点「添加我的游戏」。桌面版可以点「选择文件夹」；网页版粘贴启动器或游戏文件夹的完整路径，然后点「扫描版本」。

选中你平时启动的版本，核对 Minecraft 版本、加载器和「实际游戏目录」。在 PCL 里打开这个版本的游戏文件夹，看里面的 mods、saves 是否是你平时用的。开启版本隔离时一般在 .minecraft\versions\版本名，共用目录时一般在 .minecraft。确认后点「保存这个版本」。

保存存档并关闭 Minecraft 游戏窗口，再点该版本下的「安装伙伴 / 更新」。原有伙伴文件会备份，其他模组和存档保留。需要撤回更新时，退出游戏后点「恢复更新前的伙伴」。

进世界后怎么看、怎么聊

保持服务运行，用启动器打开装了伙伴的那个版本，进入单人世界。回到控制台的「连接与安装」，看到「已进入」和当前存档名，就说明游戏连上了。回到游戏可以看到小球，按 F8 打开伙伴面板。

看到小球不需要模型密钥。想和它聊天时，到「连接与安装」点「填写模型设置」，填入服务商给你的接口地址、API Key 和模型 ID，选择对应协议并保存。回到游戏按 T 打开原生聊天。

不确定模型 ID 时可以点「拉取模型」；接口不支持工具时可以选择「仅聊天」。请使用自己的账号，密钥由 Windows 在本机加密，换电脑后需要重新填写。保存设置不会自动发起付费聊天，「检查模型」和实际聊天可能消耗额度。按 F9 可打开截图预览，快捷键可在游戏的按键设置里修改。

下次玩同一个 ABC

打开「一起玩 MC」的本地服务，用启动器启动同一个 ABC，进单人世界。如果桌面版还在托盘里运行，就直接进游戏。只要还是原来的游戏目录、伙伴也没被移除，就不用再拖包、绑定或安装。换了一个新实例，再给新目录装一次伙伴。

几个日常入口

  • 我们的打算：新建、拆步骤、勾选、搁置、完成、删除和恢复。下次提醒会遵守安静模式。
  • 地点簿：记录家、矿洞、传送门，写明存档和维度。复制的是坐标文字，不会替你传送。
  • 聊天档案：可搜索完整记录，按存档筛选并导出 JSON。历史节选里的 #编号也能直接搜索。
  • 用量与节奏：调整主动间隔、每小时上限和每日预算。缓存读取、写入、未命中和未知会分开显示；没有缓存回执时会显示未知，不代表 0% 命中。接口不支持实时草稿时可以关闭流式回复，不会自动重试。
  • 共同记忆：纠正记错的内容，最多固定 12 条希望长期记得的设定。支持修改历史、待确认替换、约定和待续话题，旧版本不再作为当前记忆。
  • 透明上下文：查看实际请求的原文、资料来源、输入用量和稳定前缀诊断。截图只在本次发送时上传，入日记不会自动发给模型。

更新、备份与分享

更新前保存退出 MC，并从托盘退出本地服务。运行新完整包里的“更新旧版.cmd”，粘贴旧版程序目录，脚本先做程序和数据库备份，再更新程序文件。也可以直接启动新解压目录；默认共用固定数据目录。随后退出游戏，在“连接与安装”更新模组。

聊天、模型设置、角色、照片和地点默认保存在 %LOCALAPPDATA%\TogetherPlayMC\data，实际位置以“数据与恢复”显示为准。点“立即备份”保存完整快照；恢复前先退出游戏，选择备份、预览内容并确认。程序会自动保留恢复前快照。完整快照位于数据目录旁的 data-snapshots；游戏模组更新备份仍在程序目录的 work\v06-install-backups。不要把你正在用的整个程序目录直接发朋友。

分享给朋友只发干净的新装 ZIP 和校验文件。它不含你的密钥、游戏路径、存档、角色或聊天。朋友第一次打开会从空白配置开始。这个包不附带 Minecraft、Java 或整合包，继续使用朋友自己已安装好的 PCL 环境。

给伙伴挑个样子

游戏内 F8 → 设置，或网页“我的伙伴”，可以选择小灯灵、果冻团子、狗狗球、猫猫球、小云朵和口袋星球，也能保留经典小球。狗狗有八种品种，猫咪有白猫、奶牛、橘猫、黑猫和三花五款毛色。身体、口鼻、内耳、鼻尖、两种花纹和饰品等都能分别配色。换形态、品种和花纹会保留颜色；在毛色预设中点“采用”才会替换毛色，饰品与自定义表情色保留。

预览支持正面、侧面、背面和白天、洞穴光线。身体随环境明暗变化，小灯灵的光芯始终可见；光芯不改变周围方块的照明。围巾、帽子和小花都能随时穿戴和取下。纪念页记录已确认的家、实际走过的雪地，以及聊天里“送你一朵花”的心意。保存角色后，下次进入游戏仍会保留。
