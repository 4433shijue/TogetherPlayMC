TOGETHERPLAYMC 0.14 · WINDOWS

照着这几步，就能一起玩。

你负责用 PCL 启动 Minecraft，小球由这个本地程序连接。桌面与网页可以同时打开，使用同一份伙伴、日记和设置。

准备好两个东西

一个能正常进入单人世界的 Minecraft Java 1.20.1 Fabric 或 Forge 版本，以及你自己的模型接口地址、API Key 和模型名称。先在 PCL 正常玩一次，再来添加伙伴。

收到朋友发来的 TogetherPlayMC-0.14.0-Windows.zip 后，右键解压到一个固定文件夹，例如 D:\TogetherPlayMC。不要只把 EXE 拿出来，也不要在压缩包里直接运行。

1　任选一种启动方式

桌面版　双击 TogetherPlayMC.exe → 点击“开始连接”。看到控制台后继续下一步。关闭窗口会收进右下角托盘，服务继续运行。

网页版　双击 start-together.cmd。浏览器会打开本地控制台；命令窗口需要保持打开。重复启动会复用已有服务。两种方式都不需要安装 Node.js。

下方截图来自隔离的演示数据，路径和存档名称请换成你自己的。

2　添加你常玩的版本

左侧点“连接与安装” → “添加我的游戏”。桌面版可以点“选择文件夹”；网页版请打开资源管理器，点地址栏，复制 PCL 所在文件夹路径并粘贴。

点“扫描版本”，找到你平时在 PCL 启动的那个版本。支持范围会写明 1.20.1 和 Fabric / Forge。

最容易选错的一步　检查“实际游戏目录”。在 PCL 打开这个版本的设置或管理页面，使用“打开版本文件夹 / 游戏文件夹”，确认里面的 mods、saves 是你实际在用的。开启版本隔离时通常是 .minecraft\versions\版本名；共用目录通常是 .minecraft。扫描建议只是线索，要以 PCL 的实际游戏目录为准。

确认后点击“保存这个版本”。没有找到版本时，直接复制 PCL 打开的版本文件夹地址，重新扫描。只有原版、没有加载器时，先用 PCL 安装 1.20.1 Fabric 或 Forge。

3　退出游戏，再安装伙伴

在 Minecraft 保存退出，并关闭游戏窗口。回到“连接与安装”，点这个版本下面的“安装伙伴 / 更新”。完成后会核对模组哈希并显示是否与当前程序包一致；进入世界后还能查看正在运行的模组版本。

程序只安装本项目模组、连接配置和缺少的 Fabric API。原伙伴文件会备份，其他模组和存档保持原样。需要撤回这次更新时，退出游戏后点“恢复更新前的伙伴”。

4　填你自己的模型，再进入游戏

点“填写模型设置”。把服务商给你的地址、密钥、模型 ID 原样填入，选相应协议，点击保存。提供 OpenAI 兼容接口时通常选择“OpenAI 兼容”；不支持工具时可以选择“仅聊天”。不确定模型 ID 时，可手动填写或点“拉取模型”。

保存设置不会自动发起付费聊天。“检查模型”和实际聊天可能消耗额度；请使用自己的账号。程序不会提供或复制发布者的密钥。密钥由 Windows 本机加密，换电脑后重新填写。

然后照常打开 PCL，启动刚安装伙伴的版本，进入单人存档。连接状态变成“已进入……”后，就可以看到小球。T 打开 Minecraft 原生聊天，F8 管理伙伴、回忆和打算，F9 打开截图预览；快捷键可在 Minecraft 按键设置中修改。

以后只需“打开桌面版 → 开始连接 → PCL 进游戏”，或“双击 CMD → PCL 进游戏”。

几个日常入口

  • 我们的打算：新建、拆步骤、勾选、搁置、完成、删除和恢复。下次提醒会遵守安静模式。
  • 地点簿：记录家、矿洞、传送门，写明存档和维度。复制的是坐标文字，不会替你传送。
  • 聊天档案：可搜索完整记录，按存档筛选并导出 JSON。历史节选里的 #编号也能直接搜索。
  • 用量与节奏：调整主动间隔、每小时上限和每日预算。缓存读取、写入、未命中和未知会分开显示；没有缓存回执时会显示未知，不代表 0% 命中。接口不支持实时草稿时可以关闭流式回复，不会自动重试。
  • 共同记忆：纠正记错的内容，最多固定 12 条希望长期记得的设定。支持修改历史、待确认替换、约定和待续话题，旧版本不再作为当前记忆。
  • 透明上下文：查看实际请求的原文、资料来源、输入用量和稳定前缀诊断。截图只在本次发送时上传，入日记不会自动发给模型。

你看到的情况怎么做
服务启动了，但没有小球先进入单人世界；检查是否启动了安装伙伴的那个版本，到“连接与安装”重新检查。
找不到版本 / 暂不支持在 PCL 打开具体版本文件夹再扫描。必须是 Java 1.20.1 Fabric / Forge。
请先退出游戏保存存档并关掉所有 Minecraft 游戏窗口，再安装。不会强制结束你的游戏。
API Key 无效 / 没有可用内容 / 超时核对“连接模型”的地址、密钥、模型和调用方式。失败不自动重试，先看上下文和服务商状态。
端口被占用桌面开始页展开“端口被占用时”，选一个未占用端口保存后再连接；随后重新安装伙伴配置。CMD 会使用同一设置。
桌面关闭了，伙伴还在正常，窗口收进了托盘。右键托盘图标选择“退出本地服务与桌面”才会结束服务。
移动软件文件夹后连不上在新位置启动，退出游戏后重新安装伙伴配置。固定数据目录不随程序文件夹移动。
新版有问题游戏端用“恢复更新前的伙伴”；程序端可回退旧程序；需要恢复内容时，使用“数据与恢复”预览并恢复快照。恢复会替换当前内容，操作前会自动备份。

更新、备份与分享

更新前保存退出 MC，并从托盘退出本地服务。运行新完整包里的“更新旧版.cmd”，粘贴旧版程序目录，脚本先做程序和数据库备份，再更新程序文件。也可以直接启动新解压目录；默认共用固定数据目录。随后退出游戏，在“连接与安装”更新模组。

聊天、模型设置、角色、照片和地点默认保存在 %LOCALAPPDATA%\TogetherPlayMC\data，实际位置以“数据与恢复”显示为准。点“立即备份”保存完整快照；恢复前先退出游戏，选择备份、预览内容并确认。程序会自动保留恢复前快照。完整快照位于数据目录旁的 data-snapshots；游戏模组更新备份仍在程序目录的 work\v06-install-backups。不要把你正在用的整个程序目录直接发朋友。

分享给朋友只发干净的新装 ZIP 和校验文件。它不含你的密钥、游戏路径、存档、角色或聊天。朋友第一次打开会从空白配置开始。这个包不附带 Minecraft、Java 或整合包，继续使用朋友自己已安装好的 PCL 环境。

给伙伴挑个样子

游戏内 F8 → 设置，或网页“我的伙伴”，可以选择小灯灵、果冻团子、狗狗球、猫猫球、小云朵和口袋星球，也能保留经典小球。狗狗有八种品种，猫咪有白猫、奶牛、橘猫、黑猫和三花五款毛色。身体、口鼻、内耳、鼻尖、两种花纹和饰品等都能分别配色。换形态、品种和花纹会保留颜色；在毛色预设中点“采用”才会替换毛色，饰品与自定义表情色保留。

预览支持正面、侧面、背面和白天、洞穴光线。身体随环境明暗变化，小灯灵的光芯始终可见；光芯不改变周围方块的照明。围巾、帽子和小花都能随时穿戴和取下。纪念页记录已确认的家、实际走过的雪地，以及聊天里“送你一朵花”的心意。保存角色后，下次进入游戏仍会保留。
