# 整合包导入与匹配验收

在「连接与安装 → 本地整合包资料库」选择压缩包或实例目录。先离线查资料；需要游戏内使用时，核对候选实例的目录、模组和配置差异后再点「确认绑定」。仅识别到清单时，可继续匹配启动器已安装的实例，不会代替启动器下载缺少的模组。

## 实际运行

| 路径 | 验证结果 |
| --- | --- |
| 本机网页版、Windows Electron 桌面版 | 使用真实文件选择输入导入 Modrinth 测试包，搜索手册并展开来源。网页版另检查了 390 像素视口，没有资料面板横向溢出。 |
| 《元素觉醒 1.4.6》，Forge 47.4.22 | 从本机目录识别 278 个模组，提取 1,065 条 FTB 任务、10,524 条静态配方、206 条手册和 2 条脚本资料。隔离实例进入魔法协会维度后，查询返回该存档实际加载的红砖块配方。 |
| 自组 Fabric 1.20.1 | 压缩包内自定义配方以沙子制作回响碎片，安装的模组改用黏土球。匹配报告一个模组文件已修改，没有自动绑定；确认后进入实际单人世界，查询返回黏土球，原包仍能查到沙子。 |

游戏验收核对的是伙伴模组从实际游戏导出的数据，并非模型回答。没有调用付费模型、覆盖正式存档或分发第三方整合包。

## 可复验的自动化检查

运行 `node --test tests/pack-import.test.mjs`（Node.js 24）。覆盖清单与覆盖层、嵌套模组手册与配方、隐私目录排除、损坏和过大条目、取消、重启、内容去重、歧义匹配、手动确认与解除、加载器兼容性、按存档覆盖旧配方、回环上传与鉴权。

导入时不访问下载链接，也不执行包内脚本。任务资料条数不等于已知玩家进度。清单不全、未知任务系统、未导出的机器逻辑，以及未进入游戏的其他版本，均不视为已验证。

## Cobblemon 4.7.1（开发版，2026-11-24）

- 在 Edge 的「连接与安装」拖入原始 3,278,269,196 字节 7z。识别出 220 个模组、6,543 条配方、742 条手册和 2,014 条任务。两个非 Cobblemon 模组的中文语言文件无法解析，有来源警告，不阻塞其他资料。
- 搜「精灵球怎么做」，第一条为普通精灵球；来源是 Cobblemon 1.6.1 模组内的 `data/cobblemon/recipe/poke_ball.json`。四个红色球果围住符合材料标签的中心物品，一次产出四个。
- 1.21.1 Fabric 隔离单人世界：实际配方输出四个精灵球；原生聊天索要三个后收到 dropped 回执，背包从零变成三个。角色走 14.03 格，小球移动 8.55 格，最后相距 2.99 格；角色原地转身时双方水平位移均为零。使用本地模拟模型，验证的是真实游戏交付，不代表付费模型表现。
- 三种构建都走过安装、校验和恢复；本轮没有重新进入 1.20.1 的两个旧版世界。普通 RAR、7z、TAR、gzip/xz/bzip2 TAR 另有独立样本；不承诺所有 RAR 变体、加密包或缺分卷的归档。
