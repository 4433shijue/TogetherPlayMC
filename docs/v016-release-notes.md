# TogetherPlayMC 0.16.0

本版让缓存策略、请求参数和供应商回执能够互相核对。它延续 0.15.0 的本机语义检索与增量历史整理，不新增网关服务。

## 使用方法

在“连接模型”选择输入缓存策略并保存。聊天连接和独立识图连接分别设置；识图连接未启用时沿用聊天连接。

- 自动识别官方接口。严格匹配 HTTPS 域名、协议和已识别模型；Claude 为固定系统内容添加五分钟缓存标记，OpenAI 添加稳定键，DeepSeek 和 Gemini 沿用平台自动缓存。未知转发平台仅观察回执。
- 仅观测。不增加应用缓存参数，平台自己的自动缓存仍可能生效。
- Anthropic 五分钟缓存、OpenAI 稳定路由提示。供用户手动指定兼容平台使用，保存时检查协议是否匹配。平台拒绝请求后不自动重试，可自行改为仅观测。

“用量与节奏”新增模型、接口指纹和请求用途筛选。请求命中比例的分母是提供有效缓存读取字段的请求数；token 读取比例的分母是可比请求的完整输入总数。缺失、空值和非法数值保持未知；Anthropic 缺少任一输入分项时，仅将已知部分计入预算。历史记录保留，但旧口径不参与新版缓存比例。

“验证这个接口的缓存回执”先展示合成资料，点击带用量提示的开始按钮后才连续发送最多三次请求。每次最多输出 256 token，遵守已有日预算、小时次数和输入字符上限。可以随时取消；新聊天、切换伙伴或连接、关闭服务也会停止后续请求。测试记录包括输入、缓存读写、首字延迟、总耗时及对应请求记录，不写进聊天、记忆或游戏任务。已发送请求仍可能计费。

模型上下文页可检查实际缓存参数、原始数值用量字段及矛盾回执提示。固定系统内容与工具定义稳定，动态游戏状态、检索内容及当轮问题继续放在后部。

## 更新与边界

完整程序位于发行包 TogetherPlayMC 文件夹，双击 TogetherPlayMC.exe。模组兼容文件名保持不变，内部构建版本更新为 0.16.0。用户数据继续保存在 `%LOCALAPPDATA%\TogetherPlayMC\data`；已有伙伴和回忆保留。原始源码恢复包留存在开发机，不随 GitHub 公开发行；公开版本可通过本仓库的提交与标签追溯。

本版没有接入 LiteLLM、LMCache、vLLM 或语义回答缓存。参数表示应用提出了缓存请求，是否命中由供应商实际回执决定。OpenAI 新模型自动处理路由，稳定键主要用于隔离请求范围；短提示词、过期、平台改写等都可能导致零命中。没有固定折扣或延迟收益承诺。

开发验收全部使用独立数据目录与本地模拟接口，没有调用用户的付费模型。真实供应商命中率和费用需要用户主动运行测试并查看平台账单。
