# 0.16.0 验收记录

日期为 2026-11-18。验收只使用独立数据目录、本地模拟请求与离线模型；未调用用户的付费接口，未改动个人聊天数据。

## 验收范围

- Node 自动化回归 269/269 通过。覆盖未知值、非法数值、DeepSeek 命中/未命中字段、Anthropic 部分回执与预算下限、OpenAI 读写字段、矛盾回执排除、旧口径隔离和统计筛选。
- 缓存适配验证精确官方域名、HTTPS、协议与模型限制、手动覆盖、固定前缀与动态输入分离、角色/存档/用途隔离及四种协议的输出上限。
- 本地 HTTP 与 SSE 验证流式用量合并、失败时保留已收到的回执、HTTP 400 不自动重试。
- 缓存测试验证仅预览不发请求、三次串行调用、预算/限流、重复启动、过期预览、取消、关闭等待、伙伴与接口切换，以及不写入聊天、记忆、任务。
- Playwright/Edge 检查策略保存、预览、开始/取消按钮状态、表格与筛选比例、390px 窄屏和浏览器脚本错误。截图位于 screenshots/v016。
- Fabric/Forge 离线构建与嵌入版本检查；完整发行包校验全部文件哈希、两种模组、网页资源、设置持久化、稳定数据目录与备份恢复，并运行包内真实 ONNX 模型冒烟检查。

具体通过数量和机器可读结果以项目 work/v016-recovery/full-tests.log、work/v016-ui-acceptance.json、work/v016-package-acceptance.json、work/v016-archive-acceptance.json 为准。发行压缩包的每个文件都对照清单做 SHA-256 校验。
