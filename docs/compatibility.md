# 适配范围

当前目标是 Windows x64、Minecraft Java 1.20.1 的单人世界。伙伴模组分别提供 Fabric 和 Forge 构建。

| 环境 | 已有证据 | 边界 |
| --- | --- | --- |
| Fabric 0.16.14 + Fabric API 0.92.2+1.20.1 | 历史隔离单人世界验证；0.16.0 重新构建与自动化检查 | 不承诺其他游戏版本、加载器或多人服务器 |
| Forge 47.4.22 + 《元素觉醒 1.4.6》 | 历史适配、资料扫描、连接、原生聊天与 F8 交互验证 | 不是所有配方、机器、任务或整合包更新版本的全面兼容证明 |
| 0.16.0 缓存增强 | 269 项自动化回归、本地四协议 HTTP/SSE 测试、网页验收和包内检查 | 本版未重新进入游戏验证，也未测量付费接口的真实缓存收益 |

《元素觉醒》由 Sh1ntaro 制作，请通过[作者发布页](https://www.xyebbs.com/res-id/ELA)获取。该页面目前介绍的正式版采用自研 RPG 任务系统；不能把我们对 1.4.6 及 FTB Quests 的读取能力直接套用到其他版本或任务系统。

本项目只安装自身的伙伴模组及明确需要的 Fabric API。整合包的其他模组、配置、任务、素材与存档不随本项目分发。游戏资料从使用者自己的目录读取；静态脚本只作资料解析，不执行。无法覆盖的配方和进度需要玩家核实，模型不能代替真实游戏证据宣布完成。

主模式是客户端陪伴，不生成第二个玩家，也不执行采集、战斗或建筑操作。旧版操作模式属于独立实验路径，不能据此宣称《元素觉醒》的完整自动游玩支持。
