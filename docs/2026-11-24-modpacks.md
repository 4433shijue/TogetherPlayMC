# 开发版更新：从整合包到游戏里的小球

2026-11-24 · 这是 GitHub 主分支的更新，不是新的 Windows 正式发行包。已经安装的 0.16.0 不会因为这次推送自动升级。

## 整合包可以先拖进来，再装游戏

- 在「连接与安装 → 本地整合包资料库」拖入 ZIP、Modrinth、7z、RAR 或 TAR 系列压缩包，也可以读取游戏文件夹。控制台在本机识别版本、加载器和可读的模组资料。没有安装游戏，也能查到原包里的任务、手册或配方。
- 在启动器里装好同一个包，把实际游戏目录加到「匹配目录」，点「重新核对」。控制台比对模组和配置文件，列出一致、改动、缺失和额外文件。同名包、改过的包仍由你确认，不会静默绑定。
- 「资料已保存」表示原包可查；「已关联」表示绑定了目录。只有单独点「安装伙伴」才会修改该实例。关联后也可从本机补全资料，并区分原包与本机来源。
- 新手教程增加了 ABC.zip 从下载到进单人世界的完整流程。打开控制台首页的「查看新手教程」，或点拖包按钮旁的「新整合包怎么装伙伴？」即可找到。

## 游戏版本

1.20.1 Fabric / Forge 维持原有支持。新增的 1.21.1 Fabric 已在隔离的 Cobblemon 实例验证过原生聊天、跟随、赠礼拾取与配方同步。详情见[整合包导入与游戏验收](pack-import-acceptance.md)。

1.21.1 NeoForge 为独立试用目标，针对 Java 21、NeoForge 21.1 系列开发，并非把 Forge 或 Fabric 的 JAR 改名。小球绘制、客户端更新、原生聊天、伙伴面板和截图按键已接入，安装器按实例选择专用模组，不额外装 Fabric API。暂未在 All the Mods 10 或 FTB StoneBlock 4 完成整包实机验收，不计入正式支持。

## 怎么试 NeoForge

1. 使用本次源码构建的程序与模组（见[开发说明](development.md)），或在本次提交的 GitHub Actions 构建成功后，从 `neoforge-1.21.1-preview` 下载 JAR，放入同一开发版程序的 `artifacts/mods` 目录。旧正式版控制台不识别这个目标。
2. 在启动器复制一份 1.21.1 NeoForge 实例；保存退出 Minecraft，并从托盘或命令窗口退出已有本地服务。
3. 双击 `start-neoforge-preview.cmd`，按新手教程绑定复制的实例，确认路径后点「安装伙伴」。从启动器打开同一实例，进单人世界。普通启动不会开启预览安装，关闭预览服务也不会自动移除已经安装的模组。
4. 要撤回这次安装，保存并关闭游戏，在预览控制台的「连接与安装」里点「恢复更新前的伙伴」。

1.19.2 Forge、26.1.2 NeoForge 仍在候选名单，不在此次更新里。
